# Student-Management-Portal
Project planning for a Student Management Portal using Agile Scrum.
Student Management Portal

Project Description

The Student Management Portal is a web-based project designed to organize student-related information and simplify student management activities.

Objectives

- Organize student information efficiently.
- Provide a simple and user-friendly interface.
- Manage student registration and course details.
- Apply Agile Scrum methodology to plan and track project work.

Methodology

This project follows the Agile Scrum methodology. The work is organized into a Product Backlog and Sprint Plan, with progress tracked through GitHub commits and branches.

Team Roles

- Product Owner: Defines project requirements and priorities.
- Scrum Master: Helps the team follow Scrum practices.
- Development Team: Plans and develops the project features.

Repository Contents

- "Product-Backlog.md" — Project requirements and prioritized tasks.
- "Sprint-1-Plan.md" — Tasks planned for the first sprint.
- "README.md" — Project overview and documentation.

Tools Used

- GitHub
- Git and version control
- Agile Scrum
- Markdown
